# ต้นทุนและแนวคิดตั้งราคา

> **ตัวเลขทั้งหมดในไฟล์นี้เป็นการประมาณจากความรู้ทั่วไป ยังไม่ได้ตรวจกับหน้าราคาจริงของผู้ให้บริการ**
> ตอนค้นหาราคาโดเมน/VPS ผ่านเว็บ ได้ข้อมูลที่เชื่อถือไม่ได้ (หน้าเปรียบเทียบเปิดไม่ได้ และราคา .in.th ที่เจอเป็นของ reseller เจ้าเดียวที่ดูสูงผิดปกติ)
> ก่อนซื้อจริงให้เช็กหน้าราคาของแต่ละเจ้าในวันที่ซื้อ

### ช่วงที่ต้องเปิดเซิร์ฟเวอร์

- ก่อนเปิดรับสมัคร 2–4 สัปดาห์ (deploy + ทดสอบ)
- ช่วงรับสมัคร 1–2 เดือน
- หลังปิดรับถึงวันงาน (เช็กอิน รับของ) และหลังงาน (ไปรษณีย์ คืนเงิน ปิดบัญชี)
- หลังจบงาน: dump ฐานข้อมูล (เข้ารหัส) เก็บตามระยะเวลาที่จำเป็น แล้วลบข้อมูลส่วนบุคคลเมื่อหมดความจำเป็นตาม PDPA

### การเลือกผู้ให้บริการ

เกณฑ์: คิดเงินรายชั่วโมง/รายเดือนไม่ผูกสัญญา, มีโซนใกล้ไทย (สิงคโปร์), มี snapshot/backup, ย่อขยายเครื่องได้, จ่ายด้วยบัตรไทยได้และมีใบเสร็จ

| ตัวเลือก | จุดเด่น | ข้อควรระวัง |
|---|---|---|
| DigitalOcean | ใช้ง่าย เอกสารดี | มักแพงกว่าเล็กน้อย |
| Vultr | ราคาใกล้เคียง หลายโซน | เช็กโซนใกล้ไทย |
| Hetzner | มักถูกสุดต่อสเปก | เช็กว่ามีโซนเอเชียไหม |
| ผู้ให้บริการไทย (เช่น NIPA Cloud) | จ่ายบาท ซัพพอร์ตไทย | มักแพงกว่า |
| Azure / AWS | managed service ครบ | แพงสำหรับงานสั้น ค่าใช้จ่ายซับซ้อน |

แนวทางที่เอนเอียง: DigitalOcean หรือ Vultr โซนสิงคโปร์ เปิด backup รายวัน และใช้ Cloudflare หน้าเว็บ

### เครื่องตัวเอง vs เช่า VPS

- ช่วงพัฒนา/ทดสอบ: ใช้ dev server หรือ VM ตัวเองได้
- **ช่วงเปิดรับสมัครจนจบงาน: เช่า VPS** (ส่วนต่างราคาน้อย ความเสี่ยงต่างกันมาก: เน็ต/ไฟดับ/IP เปลี่ยน/CGNAT, ความปลอดภัยของข้อมูลส่วนบุคคล, ต้อง backup เอง)
- ถ้าจำเป็นต้องใช้เครื่องตัวเองจริง: Cloudflare Tunnel, UPS + เน็ตสำรอง, backup นอกเครื่อง, แยก VM ออกจากเครื่องส่วนตัว
- ไม่ควรให้ API ที่เช่าคุยกับ DB บน dev server ข้ามอินเทอร์เน็ต (ถ้าจำเป็นใช้ VPN/Tailscale + allow-list IP + เข้ารหัส)

## แนวคิดตั้งราคา (ถ้าจะขายให้ผู้จัดอื่น)

> ตัวเลขเป็นสมมติฐานตั้งต้นให้ลองเสนอ ไม่ใช่ราคาตลาดที่ตรวจสอบแล้ว

เริ่มที่ราว **฿15–25 ต่อนักวิ่ง** (หรือ 2–3% ของค่าสมัคร) พร้อมขั้นต่ำต่องาน

ตัวอย่าง 1,000 คน ค่าสมัครเฉลี่ย ฿450 (ยอดรวม ฿450,000):

| แบบคิดราคา | ได้ต่องาน |
|---|---|
| 3% ของค่าสมัคร | ฿13,500 |
| ฿20 ต่อคน | ฿20,000 |
| ค่าตั้งงาน ฿10,000 + ฿10 ต่อคน | ฿20,000 |

- แนะนำแบบผสม (ค่าตั้งงาน + ต่อคน): มีรายได้ขั้นต่ำแม้งานเล็ก และโตตามงานใหญ่ ผู้จัดประเมินต้นทุนง่าย
- ตั้งขั้นต่ำต่องาน (เช่น ฿5,000–10,000) เพราะงานเล็กใช้เวลาซัพพอร์ตไม่ต่างจากงานใหญ่
- ค่าธรรมเนียม gateway (ถ้าใช้) ต้องส่งต่อให้ผู้จัดหรือรวมในราคา
- นับต้นทุนจริงให้ครบ: เซิร์ฟเวอร์ โควต้า LINE ค่าตรวจสลิป และเวลาซัพพอร์ตช่วงเปิดรับสมัคร/วันงาน
- ถ้าบวกเป็นค่าบริการให้นักวิ่งจ่าย ต้องแสดงยอดรวมชัดเจนก่อนชำระ
- งานแรกของผู้จัดรายอื่น: อาจให้ส่วนลด/ทดลองฟรีแลกกับฟีดแบ็ก แล้วขึ้นราคางานถัดไป
- ถ้าทำฟรีให้งานของตัวเอง: ต้นทุนข้างบนต้องมีคนออก (ตัวเอง, สมาคม/ผู้จัด หรือเก็บค่าบริการเล็กน้อยต่อคน เช่น ฿5–10 ซึ่งน่าจะครอบคลุมต้นทุนโครงสร้างพื้นฐาน)

### ภาพรวมตลาด

มีแพลตฟอร์มรับสมัครงานวิ่งเจ้าใหญ่อยู่แล้ว ค่าธรรมเนียมที่เคยได้ยินราว 3–8% ต่อใบสมัคร (ตัวเลขเปลี่ยนบ่อย ต้องตรวจเอง) จุดขายควรเป็นสิ่งที่เขาไม่ทำ เช่น สมัครกลุ่ม แจ้งเตือน LINE ราคาถูกกว่า หรือปรับแต่งตามผู้จัด และต้องมีทีมซัพพอร์ตช่วงเปิดรับสมัครกับวันงาน
