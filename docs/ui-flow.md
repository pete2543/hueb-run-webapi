# UI flow และหน้าจอ

เดโมแบบคลิกดู flow สร้างไว้เป็นแคนวาส 18 หน้าจอ (ลิงก์ส่วนตัว เปิดได้เฉพาะเจ้าของจนกว่าจะกดแชร์):
https://claude.ai/artifact/X4MjVjZGTMWmEBCJ2LZNm6

ข้อมูลในเดโมทั้งหมดเป็นตัวอย่าง ส่วนที่เป็น `[ ... ]` คือค่าที่ต้องกรอกจริง (วันที่จัดงาน สถานที่ ชื่อผู้จัด บัญชีรับเงิน ฯลฯ) QR ในเดโมเป็นภาพตัวอย่าง สแกนไม่ได้

## ฝั่งนักวิ่ง (mobile-first)

| # | หน้า | เส้นทางที่เสนอ | สิ่งที่มี |
|---|---|---|---|

| 2 | เลือกระยะ | `/register` | การ์ดเลือกระยะ ราคา early bird แถบโควตาเหลือ (เตือนเมื่อใกล้เต็ม) |
| 3 | ข้อมูลนักวิ่ง | `/register/runners` | ฟอร์มนักวิ่ง (คำนำหน้า ชื่อ วันเกิด สัญชาติ เพศ เบอร์ ไซซ์เสื้อ) ผู้ติดต่อฉุกเฉิน กรุ๊ปเลือด โรคประจำตัว/แพ้ยา ปุ่มเพิ่มนักวิ่งอีกคน ยอมรับ PDPA |

## Design tokens (ธีม HUEB RUN · ธีมสว่าง)

ใช้แทนสีของเดโมในแคนวาส (เดโมยังเป็นธีมมืดสีเขียว ตอนทำหน้าจริงให้ใช้สีชุดนี้) ค่าจริงอยู่ที่ `src/app/globals.css`

สีหลัก 5 สี (concept "Alumni Run · พลังของการวิ่ง · ความผูกพันของศิษย์เก่า"):

| สี | ค่า | Token | ใช้กับ |
|---|---|---|---|
| Royal Blue | `#124BC5` | `primary`, `ring` | สีหลัก ปุ่มหลัก ลิงก์ ขั้นตอนที่เสร็จ |
| Deep Navy | `#102A56` | `foreground` | หัวข้อ ข้อความ |
| White | `#FFFFFF` | `background`, `card` | พื้นหลัก การ์ด |
| Ice Blue | `#EAF2FF` | `secondary`, `muted`, `accent`, `surface-raised`, `sidebar` | พื้นรอง แบ่งส่วน แถวที่เลือก |
| Warm Gold | `#F3C65B` | `gold` | จุดเน้นเล็กน้อย (แถบ ป้าย ไฮไลต์) |

สีที่แตกออกมาเพื่อใช้งาน (ยังไม่อยู่ในชุดสีหลัก ปรับได้):

| Token | ค่า | ใช้กับ |
|---|---|---|
| border / input | `#D3E0F7` | เส้นขอบ (Ice Blue บนพื้นขาวจางเกินจะเห็น) |
| muted-foreground | `#4A5F85` | ข้อความรอง |
| warning / destructive | `#D9480F` | ใกล้เต็ม หมดเวลา ปฏิเสธ |
| caution | `#B7791F` | รอตรวจ |

- Warm Gold contrast ต่ำบนพื้นขาว **ห้ามใช้เป็นสีตัวอักษรบนพื้นขาว** ใช้เป็นพื้นคู่กับตัวอักษร Deep Navy หรือใช้เป็นตัวอักษรบนพื้น Royal Blue (แบบโลโก้ใน concept)
- ฟอนต์: **Prompt** (หัวข้อ/ตัวเลข) และ **Noto Sans Thai** (เนื้อหา)
- ปุ่มและพื้นที่กดอย่างน้อย 44px (ใช้งานบนมือถือ)

## หมายเหตุสำหรับตอน implement

- หน้า 1 เท่านั้นที่มี 3D ให้โหลดแบบ lazy (`next/dynamic`, `ssr: false`) มีภาพนิ่งสำรองสำหรับมือถือรุ่นเก่า และเคารพ `prefers-reduced-motion`
- ไฟล์โมเดล 3D ใช้ `.glb` บีบอัด (Draco) ให้ไม่เกิน ~1–3MB และเสิร์ฟผ่าน CDN
- หน้า 2–6 (ขั้นตอนสมัคร) ต้องเบาและเร็วที่สุด ห้ามให้ 3D หรือสคริปต์หนักไปขัดขวางการสมัคร
- เดโมใช้ `<a>` ลิงก์ระหว่างหน้า; ของจริงเก็บข้อมูลหลายนักวิ่งไว้ใน state ของ flow (หรือ draft ฝั่ง server) ไม่ใช่แค่ query string
- ใช้ `<label>` กับ `<input>` จริง, ปุ่มเป็น `<button>`, ไอคอนล้วนต้องมี `aria-label`
